| Data Type | Description |
| :---: | :---: |
| int | Stores whole signed integer values. |
| float | Stores single-precision floating-point values. |
| double | Stores double-precision floating-point values. |
| char | Stores a single character. |
| bool | Represents a Boolean true/false value when supported through the appropriate C definition. |
| void | Represents absence of a value/type. |

| Format Specifiers |
| :---: |
| %d |
| %u |
| %o |
| %x |
| %X |
| %f |
| %e |
| %c |
| %s |
| %ld |

scanf(): Reads formatted input from the user.  
printf(): Displays formatted output.  
getchar(): Reads one character from standard input.  
putchar(): Displays one character.  
fgets(): Reads a line of text, including spaces, into a character array.  
puts(): Displays a string followed by a newline.  

\n — Moves output to a new line.  
\t — Inserts a horizontal tab.  
\\ — Displays a backslash.  
\" — Displays a double quotation mark.  
\' — Displays a single quotation mark  

For floating-point output, precision is specified by placing a dot followed by the required number of digits before the conversion specifier. For example, %.2f displays two digits after the decimal point, while %.4f displays four.
